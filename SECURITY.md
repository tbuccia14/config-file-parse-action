# Security Policy

## Supported Versions

Only the latest major version tag (e.g. `v1`) receives security fixes. Older, unpinned
commit SHAs are not maintained.

## Reporting a Vulnerability

If you discover a security vulnerability in this action, please **do not** open a public issue. Instead, report it privately using [GitHub's private vulnerability reporting](../../security/advisories/new) for this repository.

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof of concept
- Any suggested remediation, if known

You should expect an initial response within a few business days. Once a fix is available, a new release will be published and, where applicable, a GitHub Security Advisory will be issued.
